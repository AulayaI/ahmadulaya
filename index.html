TUTORIAL INSTALL MOODLE 5.0 100% WORK

(cocok untuk pemula)

1. KONFIGURASI MIKROTIK (CHR)

▼
  1. Tambahkan Network Device int_br0 dan int_br1 di Proxmox.
  2. Cek IP: /ip address print
  3. Akses Winbox, buat Bridge1, masukkan port eth2 & eth3.
  4. Setting IP Gateway (Bridge1):
    IP Address: 10.12.X.1
    Interface: bridge1
  5. Firewall NAT:
    Chain: srcnat
    Action: Masquerade
  6. DST-NAT (Port Forwarding):
    Chain: dstnat
    In. Interface: eth1
    Action: dst-nat | To Address: 10.12.X.2 (ip web server)
  7. Jangan lupa setting static masing masing CT:
    CT WEB SERVER : 10.12.X.2/24
    CT DATABASE : 10.12.X.3/24
    Cek IP dan koneksi internet

2. INSTALASI WEB SERVER

▼
  1. Edit Nginx Default: nano /etc/nginx/sites-available/default
    2. Tambahkan index.php
    Edit fastcgi php7.4-fpm > php8.4-fpm
    Hapus # pada beberapa baris berikut:
    location // include // fastcgi // kurung "}"
  2. Restart Service:
    systemctl restart nginx
    systemctl status nginx
    systemctl status php8.4-fpm
  3. Cek Koneksi Database:
    mysql -u username -h IP_DB_SERVER -P 3306 -p
  4. Buat file test PHP: nano /var/www/html/test.db 
    <?php
                    $host     = 'IP_DB';      // Ganti dengan IP server DB
                    $port     = '3306';
                    $dbname   = 'nama_db';
                    $username = 'username_db';
                    $password = 'pw_db';

                    try {
                        $dsn = "mysql:host=$host;port=$port;dbname=$dbname;charset=utf8mb4";
                        
                        $pdo = new PDO($dsn, $username, $password, [
                            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
                        ]);
                        
                        echo "<h2 style='color:green;'>✅ Koneksi Database SUKSES!</h2>";
                        echo "<p>Server: " . $pdo->getAttribute(PDO::ATTR_SERVER_INFO) . "</p>";
                        echo "<p>Client: " . $pdo->getAttribute(PDO::ATTR_CLIENT_VERSION) . "</p>";
                        
                        // Test query sederhana
                        $stmt = $pdo->query("SELECT VERSION() as version");
                        $row  = $stmt->fetch();
                        
                        echo "<p>MariaDB Version: " . $row['version'] . "</p>";

                    } catch (PDOException $e) {
                        echo "<h2 style='color:red;'>❌ Koneksi GAGAL!</h2>";
                        echo "<p>Error: " . $e->getMessage() . "</p>";
                        echo "<p>Host: $host:$port | DB: $dbname</p>";
                    }

                    $pdo = null; // Tutup koneksi
                    ?>
  5. Cek status nginx dengan IP Mikrotik masing masing:172.20.2.X

3. INSTALASI DATABASE

▼
  1. Edit Config: nano /etc/mysql/mariadb.conf.d/50-server.cnf
    bind-address = 0.0.0.0
  2. Login ke mysql: mysql -u root -p
  3. Query Database:
    CREATE DATABASE database_name;
    CREATE USER 'username'@'%' IDENTIFIED BY 'password';
    GRANT ALL PRIVILEGES ON database_name.* TO 'username'@'%';
    FLUSH PRIVILEGES;
    EXIT;
  4. Restart: systemctl restart mariadb

4. INSTALASI MOODLE

▼

A. Buat database baru (VM CT DATABASE)

  1. Login ke mysql: mysql -u root -p
  2. Query Database:
    CREATE DATABASE moodle DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    CREATE USER 'moodleuser'@'%' IDENTIFIED BY 'password';
    GRANT ALL PRIVILEGES ON moodle.* TO 'moodleuser'@'%';
    FLUSH PRIVILEGES;
    EXIT;

B. Konfigurasi PHP (VM CT WEB SERVER)

  1. Edit: nano /etc/php/8.4/fpm/php.ini
  2. Ubah nilai berikut:
    max_input_vars = 5000
    memory_limit = 256M
    post_max_size = 100M
    upload_max_filesize = 100M
  3. Restart: systemctl restart php8.4-fpm

C. Download & Permission

  1. Download Moodle:
    cd /var/www/html/
    wget http://192.168.0.254/moodle-5.0.tgz
    tar -zxvf moodle-5.0.tgz
  2. Hak Akses Folder:
    mkdir /var/moodledata
    chown -R www-data:www-data /var/www/html/moodle
    chown -R www-data:www-data /var/moodledata
    chmod -R 755 /var/moodledata

D. Konfigurasi Nginx (Moodle)

Buat file: nano /etc/nginx/sites-available/moodle

Isi dengan script berikut (1 Block Utuh):

server {
                listen 80 default_server;
                server_name your_domain_or_ip;
                root /var/www/html/moodle;
                index index.php;
                client_max_body_size 100M;

                location / {
                    try_files $uri $uri/ =404;
                }

                location ~ [^/]\.php(/|$) {
                    fastcgi_split_path_info ^(.+\.php)(/.+)$;
                    fastcgi_pass unix:/var/run/php/php8.4-fpm.sock;
                    fastcgi_index index.php;
                    include fastcgi_params;
                    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
                    fastcgi_param PATH_INFO $fastcgi_path_info;
                }

                location /dataroot/ {
                    internal;
                    alias /var/moodledata/;
                }
            }

D. Finishing

  1. Aktifkan Site:
    ln -s /etc/nginx/sites-available/moodle /etc/nginx/sites-enabled/
    rm /etc/nginx/sites-enabled/default
    nginx -t
    systemctl restart nginx
  2. Buka browser, ketik IP, dan selesaikan instalasi.
